01 / Overview

A clear place for every part of trigger work.

This Salesforce DX package brings trigger context, handler orchestration, action configuration, bypass management, and asynchronous execution into one cohesive framework. Configure behavior with metadata while keeping Apex responsibilities explicit.

03 / Components

Small building blocks.
One consistent pattern.

01 — CONTRACT

ITriggerHandler

The interface that defines the framework's trigger handler contract.

02 — CONTEXT

TriggerContext

A focused representation of the current trigger execution context.

03 — ORCHESTRATION

TriggerHandler

The base handler responsible for coordinating framework trigger work.

04 — ASYNC

AsyncTriggerHandler

A dedicated handler for asynchronous trigger execution.

05 — CONTROL

TriggerBypassManager

Centralized bypass management backed by the Trigger_Bypass__c setting.

06 — CONFIGURATION

Custom metadata

Trigger_Handler_Config__mdt and Trigger_Action__mdt hold framework configuration.

07 — UTILITIES

TriggerHandlerUtils

Shared utility methods and constants used throughout the framework.

08 — EXAMPLE

Account implementation

An example Account trigger and handler show how the framework is applied.

05 / Deploy & verify

From source to org.
On your terms.

Deploy with manifest 
sf project deploy start --manifest manifest/package.xml
Deploy source 
sf project deploy start --source-dir force-app
Validate before deploy 
sf project deploy validate --manifest manifest/package.xml
Run Apex tests 
sf apex test run --test-level RunLocalTests --result-format human
Create a scratch org 
sf org create scratch --definition-file config/project-scratch-def.json --alias trigger-framework
sf project deploy start --source-dir force-app
